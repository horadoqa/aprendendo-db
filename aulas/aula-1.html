AULA 1 • FUNDAMENTOS DE BANCO DE DADOS

Banco de Dados, SGBD e Aplicação

Entenda a diferença entre os dados, o software que gerencia esses dados e a aplicação que utiliza essas informações.

Objetivos da aula

Antes de aprender SQL, modelagem ou NoSQL, é importante entender alguns conceitos fundamentais.

Nesta aula, você vai aprender a diferenciar:

🗄️

Banco de Dados

Onde os dados são armazenados e organizados.

⚙️

SGBD

Software responsável por gerenciar os bancos de dados.

💻

Aplicação

Software que oferece funcionalidades aos usuários e utiliza os dados.

Os três conceitos em uma visão geral

Uma aplicação normalmente precisa armazenar e consultar informações. Para isso, ela utiliza um SGBD, que por sua vez gerencia um ou mais bancos de dados.

Aplicação → solicita operações.

SGBD → gerencia essas operações.

Banco de Dados → contém os dados armazenados.

Essa separação de responsabilidades é uma das ideias fundamentais para compreender como os sistemas que trabalham com dados são construídos.

1. O que é um Banco de Dados?

Um banco de dados é uma coleção organizada de dados que pode ser armazenada, consultada e modificada de acordo com as necessidades de um sistema.

Os dados armazenados dependem do objetivo da aplicação. Uma loja virtual, por exemplo, pode armazenar informações sobre clientes, produtos e pedidos.

👤

Clientes

Nome, e-mail, telefone e endereço.

📦

Produtos

Nome, preço, estoque e categoria.

🛒

Pedidos

Cliente, produtos, quantidades e valores.

💳

Pagamentos

Valor, método e status do pagamento.

Importante:

O banco de dados representa os dados armazenados e organizados. Ele não é a aplicação que o usuário utiliza.

Exemplo de um banco de dados

Em um banco de dados relacional, os dados podem ser organizados em tabelas.

Imagine uma tabela responsável por armazenar informações dos clientes:

ID Nome E-mail Cidade
1 Ana Silva ana@email.com Rio de Janeiro
2 João Santos joao@email.com São Paulo
3 Maria Oliveira maria@email.com Belo Horizonte

Nesse exemplo, os registros dos clientes fazem parte dos dados armazenados no banco.

2. O que é um SGBD?

SGBD significa Sistema de Gerenciamento de Banco de Dados.

O SGBD é o software responsável por gerenciar bancos de dados e fornecer mecanismos para que aplicações possam trabalhar com os dados armazenados.

Entre suas responsabilidades estão operações de consulta e alteração de dados, controle de acesso, gerenciamento de transações e outros mecanismos necessários para o funcionamento do banco.

Uma forma simples de entender:

O banco de dados contém os dados. O SGBD é o software que gerencia esses dados.

Exemplos de SGBDs

Existem diferentes tipos de SGBDs, desenvolvidos para diferentes modelos de armazenamento.

RELACIONAL

PostgreSQL

SGBD relacional que utiliza SQL para trabalhar com bancos de dados relacionais.

RELACIONAL

MySQL

SGBD relacional amplamente utilizado em aplicações e sistemas web.

DOCUMENTOS

MongoDB

SGBD orientado a documentos, baseado em um modelo de dados diferente do relacional.

3. O que é uma Aplicação?

Uma aplicação é um software criado para realizar determinadas tarefas e oferecer funcionalidades aos usuários ou a outros sistemas.

Uma aplicação pode ser um site, aplicativo de celular, sistema empresarial, API, programa desktop ou outro tipo de software.

🛒

E-commerce

Permite pesquisar produtos, realizar compras e acompanhar pedidos.

📱

Aplicativo

Permite que o usuário execute operações através de uma interface.

🔌

API

Permite que diferentes sistemas se comuniquem e troquem informações.

Como eles trabalham juntos?

Imagine uma pessoa acessando uma loja virtual e consultando seus pedidos.

👤

1. Usuário

Solicita uma ação através da aplicação.

💻

2. Aplicação

Recebe a solicitação e executa as regras necessárias.

⚙️

3. SGBD

Processa as operações solicitadas pela aplicação.

🗄️

4. Banco de Dados

Contém os dados que precisam ser consultados ou modificados.

Exemplo prático

Imagine que um cliente queira consultar seus pedidos.

1. Usuário: solicita "Meus pedidos".

↓

2. Aplicação: recebe a solicitação e identifica o cliente.

↓

3. SGBD: recebe uma operação solicitada pela aplicação.

↓

4. Banco de Dados: contém os registros dos pedidos.

↓

5. Aplicação: apresenta os resultados para o usuário.

E onde entra o SQL?

Agora podemos introduzir mais um conceito: SQL.

SQL significa Structured Query Language. É uma linguagem utilizada principalmente para consultar e manipular dados em bancos de dados relacionais.

Não confunda:

SQL não é um banco de dados.

SQL não é um SGBD.

SQL é uma linguagem utilizada para trabalhar com bancos de dados relacionais.

Um exemplo de SQL

Uma aplicação pode solicitar ao SGBD uma consulta como esta: 

SELECT *
FROM clientes
WHERE cidade = 'Rio de Janeiro';

O SQL descreve a operação que queremos realizar. O SGBD é responsável por interpretar essa operação e trabalhar com o banco de dados.

Banco de Dados × SGBD × Aplicação × SQL

Conceito O que é? Função Exemplo
Banco de Dados Coleção organizada de dados. Armazenar e organizar informações. Dados de clientes, produtos e pedidos.
SGBD Software de gerenciamento de banco de dados. Gerenciar o armazenamento e o acesso aos dados. PostgreSQL, MySQL, MongoDB.
Aplicação Software que implementa funcionalidades. Permitir que usuários ou sistemas realizem operações. E-commerce, aplicativo ou API.
SQL Linguagem. Expressar operações sobre dados em bancos relacionais. SELECT, INSERT, UPDATE, DELETE.

Uma analogia para memorizar

Imagine uma biblioteca.

📚

Banco de Dados

É como o acervo da biblioteca: contém as informações armazenadas.

⚙️

SGBD

É como o sistema responsável por organizar e controlar o acesso ao acervo.

🖥️

Aplicação

É como a interface utilizada pelo usuário para realizar suas solicitações.

🔎

SQL

É como uma linguagem usada para expressar o que queremos encontrar ou modificar no acervo.

Erros comuns

❌ "PostgreSQL é um banco de dados"

De forma mais precisa, PostgreSQL é um SGBD relacional. Ele pode gerenciar bancos de dados.

❌ "SQL é um banco de dados"

SQL é uma linguagem. Ele é utilizado principalmente para trabalhar com bancos de dados relacionais.

❌ "O site é o banco de dados"

O site faz parte da aplicação. A aplicação pode utilizar um SGBD para acessar os dados.

❌ "O banco de dados é a aplicação"

São componentes diferentes. A aplicação implementa funcionalidades, enquanto o banco armazena os dados.

Resumindo

🗄️ Banco de Dados → é onde os dados são armazenados e organizados.

⚙️ SGBD → é o software que gerencia os bancos de dados.

💻 Aplicação → é o software que implementa funcionalidades e utiliza os dados.

🔤 SQL → é uma linguagem utilizada principalmente para trabalhar com bancos de dados relacionais.

A partir desses conceitos, podemos começar a estudar como os dados são modelados, relacionados e consultados.
