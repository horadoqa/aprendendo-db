O comando SELECT

O SELECT é utilizado para consultar dados.

Sua estrutura básica é: 

SELECT coluna
FROM tabela;

Podemos consultar uma única coluna: 

SELECT nome
FROM clientes;

Ou várias: 

SELECT nome, email
FROM clientes;

Também podemos consultar todas: 

SELECT *
FROM clientes;

Filtrando dados com WHERE

O WHERE permite definir uma condição para determinar quais registros serão retornados.

Imagine a seguinte tabela:

ID Nome Idade Cidade
1 Ana 20 Rio de Janeiro
2 João 25 São Paulo
3 Maria 19 Rio de Janeiro
4 Pedro 30 Belo Horizonte

Podemos buscar somente os clientes do Rio de Janeiro: 

SELECT *
FROM clientes
WHERE cidade = 'Rio de Janeiro';

O resultado será composto somente pelos registros que atendem à condição.

Operadores de comparação

O WHERE pode utilizar diferentes operadores.

Operador Significado Exemplo
= Igual idade = 20
<> Diferente idade <> 20
> Maior que idade > 20
< Menor que idade < 20
>= Maior ou igual idade >= 20
<= Menor ou igual idade <= 20

Exemplo: 

SELECT *
FROM clientes
WHERE idade > 20;

Essa consulta retorna somente clientes com idade superior a 20 anos.

Utilizando AND

O operador AND permite combinar duas ou mais condições.

Por exemplo, podemos procurar clientes do Rio de Janeiro com idade maior que 20: 

SELECT *
FROM clientes
WHERE cidade = 'Rio de Janeiro'
AND idade > 20;
AND significa "E".

As duas condições precisam ser verdadeiras para que o registro seja retornado.

Utilizando OR

O operador OR permite trabalhar com alternativas.

Podemos procurar clientes que estejam no Rio de Janeiro ou em São Paulo: 

SELECT *
FROM clientes
WHERE cidade = 'Rio de Janeiro'
OR cidade = 'São Paulo';
OR significa "OU".

Basta uma das condições ser verdadeira para que o registro possa ser retornado.

Utilizando NOT

O operador NOT é utilizado para negar uma condição.

Por exemplo: 

SELECT *
FROM clientes
WHERE NOT cidade = 'Rio de Janeiro';

Nesse caso, serão considerados os registros que não possuem a cidade informada.

Utilizando IN

Quando precisamos verificar se um valor pertence a uma lista de possibilidades, podemos utilizar IN.

Em vez de escrever: 

WHERE cidade = 'Rio de Janeiro'
OR cidade = 'São Paulo'
OR cidade = 'Belo Horizonte'

Podemos escrever: 

SELECT *
FROM clientes
WHERE cidade IN (
    'Rio de Janeiro',
    'São Paulo',
    'Belo Horizonte'
);
IN

É útil quando temos uma lista de valores possíveis.

Utilizando BETWEEN

O BETWEEN pode ser utilizado para verificar se um valor está dentro de um intervalo.

Por exemplo, clientes com idade entre 20 e 30: 

SELECT *
FROM clientes
WHERE idade BETWEEN 20 AND 30;

O intervalo do exemplo inclui os valores das extremidades.

Procurando textos com LIKE

O operador LIKE permite realizar buscas por padrões em textos.

Por exemplo, para procurar nomes que começam com "A": 

SELECT *
FROM clientes
WHERE nome LIKE 'A%';

O símbolo % representa uma sequência de caracteres.

Outro exemplo: 

SELECT *
FROM clientes
WHERE nome LIKE '%Silva%';

Nesse caso, estamos procurando nomes que contenham "Silva".

Padrão Significado
A% Começa com A.
%A Termina com A.
%A% Contém A.

Ordenando resultados com ORDER BY

O ORDER BY permite definir a ordem dos resultados.

Para ordenar pela idade: 

SELECT *
FROM clientes
ORDER BY idade;

Por padrão, a ordenação é crescente.

Podemos deixar isso explícito utilizando ASC: 

SELECT *
FROM clientes
ORDER BY idade ASC;

Para ordenar de forma decrescente: 

SELECT *
FROM clientes
ORDER BY idade DESC;

ASC → crescente

DESC → decrescente

Limitando resultados com LIMIT

O LIMIT permite limitar a quantidade de registros retornados.

Por exemplo, podemos solicitar apenas cinco clientes: 

SELECT *
FROM clientes
LIMIT 5;

Podemos combinar LIMIT com ORDER BY.

Por exemplo, para consultar os três clientes mais velhos: 

SELECT *
FROM clientes
ORDER BY idade DESC
LIMIT 3;
Observação:

A sintaxe e o comportamento de LIMIT podem variar entre SGBDs. Em PostgreSQL e MySQL, por exemplo, LIMIT é amplamente utilizado.

Removendo valores repetidos com DISTINCT

O DISTINCT permite retornar somente valores diferentes.

Imagine que vários clientes moram na mesma cidade.

Uma consulta normal: 

SELECT cidade
FROM clientes;

Poderia retornar:

Rio de Janeiro

São Paulo

Rio de Janeiro

Belo Horizonte

Utilizando DISTINCT: 

SELECT DISTINCT cidade
FROM clientes;

Teremos cada cidade somente uma vez.

Combinando os recursos

O verdadeiro poder das consultas aparece quando combinamos diferentes cláusulas.

Por exemplo: 

SELECT nome, idade, cidade
FROM clientes
WHERE idade >= 18
AND cidade = 'Rio de Janeiro'
ORDER BY idade DESC
LIMIT 5;

Essa consulta:

  1. seleciona nome, idade e cidade;
  2. utiliza a tabela clientes;
  3. filtra clientes maiores ou iguais a 18 anos;
  4. mantém somente clientes do Rio de Janeiro;
  5. ordena pela idade de forma decrescente;
  6. retorna no máximo cinco registros.

A ordem das cláusulas

É importante aprender a estrutura de uma consulta SQL. 

SELECT colunas
FROM tabela
WHERE condição
ORDER BY coluna
LIMIT quantidade;
Cláusula Função
SELECT Define quais colunas serão retornadas.
FROM Define de qual tabela os dados serão obtidos.
WHERE Filtra os registros.
ORDER BY Ordena os resultados.
LIMIT Limita a quantidade de resultados.

Exemplo prático — Produtos

Vamos imaginar uma tabela chamada produtos:

ID Nome Preço Estoque
1 Notebook 3500 10
2 Mouse 80 50
3 Teclado 150 25
4 Monitor 1200 8
5 Headset 250 15

Produtos acima de R$ 200 

SELECT *
FROM produtos
WHERE preco > 200;

Produtos ordenados pelo preço 

SELECT nome, preco
FROM produtos
ORDER BY preco DESC;

Os três produtos mais baratos 

SELECT nome, preco
FROM produtos
ORDER BY preco ASC
LIMIT 3;

Produtos com estoque baixo 

SELECT nome, estoque
FROM produtos
WHERE estoque < 10;

⚠️ Erros comuns

Esquecer o WHERE

Em consultas isso pode retornar muito mais dados do que o necessário.

Usar SELECT *

É útil para estudar, mas em aplicações nem sempre é necessário buscar todas as colunas.

Confundir = com LIKE

O operador = compara valores. LIKE trabalha com padrões de texto.

Esquecer ORDER BY

Não devemos assumir uma ordem específica dos resultados sem solicitar uma ordenação.

🎯 Desafio da aula

Imagine que você trabalha em uma loja virtual e recebeu a seguinte solicitação:

"Preciso dos nomes e preços dos cinco produtos mais caros que custam pelo menos R$ 100."

Tente construir a consulta sozinho.

Uma solução possível: 

SELECT nome, preco
FROM produtos
WHERE preco >= 100
ORDER BY preco DESC
LIMIT 5;

Perceba que uma única consulta pode combinar vários recursos aprendidos nesta aula.
