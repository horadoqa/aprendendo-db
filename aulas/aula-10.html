AULA 10 • WINDOW FUNCTIONS

Window Functions

Aprenda a analisar e comparar registros relacionados sem perder as linhas individuais do resultado.

Objetivos da aula

Nas aulas anteriores aprendemos a utilizar GROUP BY, funções de agregação, JOIN, subconsultas e CTEs.

Agora vamos aprender uma ferramenta muito importante para análise de dados: as Window Functions.

🪟

Window Functions

Realizar cálculos considerando outras linhas relacionadas.

🔢

ROW_NUMBER

Numerar linhas dentro de um conjunto de dados.

🏆

RANK

Criar classificações e rankings.

↔️

LAG e LEAD

Comparar uma linha com linhas anteriores ou posteriores.

O que é uma Window Function?

Uma Window Function, ou função de janela, permite realizar cálculos utilizando um conjunto de linhas relacionadas à linha atual.

Uma diferença importante:

O GROUP BY normalmente reduz várias linhas em uma única linha por grupo.

Uma Window Function realiza o cálculo, mas mantém as linhas individuais no resultado.

Essa diferença é fundamental para entender funções de janela.

GROUP BY × Window Function

Imagine a seguinte tabela:

Cliente Pedido Total
Ana 101 500
Ana 102 300
João 103 700

Com GROUP BY, poderíamos calcular o total de cada cliente: 

SELECT

    cliente_id,

    SUM(total) AS total_cliente

FROM pedidos

GROUP BY cliente_id;

O resultado teria uma linha por cliente.

Com uma Window Function, podemos manter cada pedido e ainda mostrar o total daquele cliente: 

SELECT

    cliente_id,

    id,

    total,

    SUM(total)
        OVER (
            PARTITION BY cliente_id
        ) AS total_cliente

FROM pedidos;

A palavra-chave OVER

A cláusula OVER é uma das partes fundamentais das Window Functions. 

SUM(total)
OVER (
    ...
)

Ela define a janela de linhas que será utilizada no cálculo.

Pense assim:

OVER define "sobre quais linhas o cálculo deve olhar".

PARTITION BY

PARTITION BY divide os registros em grupos para que a Window Function seja calculada separadamente em cada grupo.

Por exemplo, podemos calcular o total de pedidos separadamente para cada cliente. 

SELECT

    cliente_id,

    id,

    total,

    SUM(total)
    OVER (

        PARTITION BY cliente_id

    ) AS total_cliente

FROM pedidos;

PARTITION BY cliente_id significa:

"Faça o cálculo separadamente para cada cliente."

ORDER BY dentro do OVER

Também podemos utilizar ORDER BY dentro da janela.

Isso permite definir a ordem em que os registros serão analisados. 

SELECT

    id,

    cliente_id,

    total,

    SUM(total)
    OVER (

        PARTITION BY cliente_id

        ORDER BY id

    ) AS total_acumulado

FROM pedidos;

Agora podemos obter um total acumulado.

ROW_NUMBER()

A função ROW_NUMBER() atribui um número sequencial para cada linha dentro da janela. 

SELECT

    id,

    cliente_id,

    total,

    ROW_NUMBER()
    OVER (

        ORDER BY total DESC

    ) AS posicao

FROM pedidos;

O pedido de maior valor receberá posição 1, o segundo receberá posição 2 e assim por diante.

Também podemos reiniciar a numeração para cada cliente: 

SELECT

    id,

    cliente_id,

    total,

    ROW_NUMBER()
    OVER (

        PARTITION BY cliente_id

        ORDER BY total DESC

    ) AS posicao

FROM pedidos;

Nesse caso, cada cliente começa novamente na posição 1.

RANK()

A função RANK() cria uma classificação considerando empates. 

SELECT

    id,

    total,

    RANK()
    OVER (

        ORDER BY total DESC

    ) AS ranking

FROM pedidos;

Imagine os valores: 

1000
900
900
500

Com RANK(), o resultado será: 

1
2
2
4

Observe que a posição 3 é pulada devido ao empate.

DENSE_RANK()

O DENSE_RANK() também considera empates, mas não pula posições. 

SELECT

    id,

    total,

    DENSE_RANK()
    OVER (

        ORDER BY total DESC

    ) AS ranking

FROM pedidos;

Para os valores: 

1000
900
900
500

O resultado será: 

1
2
2
3
Função Resultado
ROW_NUMBER() 1, 2, 3, 4
RANK() 1, 2, 2, 4
DENSE_RANK() 1, 2, 2, 3

LAG()

A função LAG() permite acessar o valor de uma linha anterior. 

SELECT

    id,

    total,

    LAG(total)
    OVER (

        ORDER BY id

    ) AS total_anterior

FROM pedidos;

Imagine: 

Pedido     Total

1          100
2          200
3          150

O resultado poderia ser: 

Pedido     Total     Total anterior

1          100       NULL
2          200       100
3          150       200

A primeira linha não possui uma linha anterior, por isso o resultado é NULL.

LEAD()

A função LEAD() faz o contrário de LAG: permite acessar o valor de uma linha posterior. 

SELECT

    id,

    total,

    LEAD(total)
    OVER (

        ORDER BY id

    ) AS proximo_total

FROM pedidos;
Função Acessa
LAG() Linha anterior
LEAD() Próxima linha

Comparando valores

Podemos utilizar LAG para descobrir a diferença entre um pedido e o pedido anterior. 

SELECT

    id,

    total,

    LAG(total)
    OVER (

        ORDER BY id

    ) AS total_anterior,

    total -

    LAG(total)
    OVER (

        ORDER BY id

    ) AS diferenca

FROM pedidos;

Isso permite realizar análises de evolução, variação e comparação entre períodos.

Total acumulado

Window Functions também permitem calcular valores acumulados. 

SELECT

    id,

    total,

    SUM(total)
    OVER (

        ORDER BY id

    ) AS total_acumulado

FROM pedidos;

Se os pedidos forem: 

100
200
300

O total acumulado será: 

100
300
600
Esse recurso é muito utilizado em:
  • Relatórios financeiros.
  • Análise de vendas.
  • Indicadores acumulados.
  • Análise de crescimento.

Média móvel

Também podemos calcular uma média considerando um determinado conjunto de linhas ao redor da linha atual. 

SELECT

    id,

    total,

    AVG(total)
    OVER (

        ORDER BY id

        ROWS BETWEEN
        2 PRECEDING
        AND CURRENT ROW

    ) AS media_movel

FROM pedidos;

Nesse exemplo, a média considera a linha atual e até duas linhas anteriores.

Encontrando o primeiro registro de cada grupo

Um uso muito comum de Window Functions é encontrar o primeiro ou o último registro de cada grupo.

Por exemplo, podemos encontrar o maior pedido de cada cliente. 

WITH pedidos_ordenados AS (

    SELECT

        id,

        cliente_id,

        total,

        ROW_NUMBER()
        OVER (

            PARTITION BY cliente_id

            ORDER BY total DESC

        ) AS posicao

    FROM pedidos

)


SELECT

    id,

    cliente_id,

    total

FROM pedidos_ordenados

WHERE posicao = 1;

A Window Function cria a posição.

A CTE permite depois filtrar essa posição.

PARTITION BY na prática

Imagine que queremos criar um ranking de pedidos separado para cada cliente. 

SELECT

    cliente_id,

    id,

    total,

    RANK()
    OVER (

        PARTITION BY cliente_id

        ORDER BY total DESC

    ) AS ranking

FROM pedidos;

Cada cliente terá seu próprio ranking.

Sem PARTITION BY: existe um ranking geral.

Com PARTITION BY cliente_id: existe um ranking para cada cliente.

Principais Window Functions

Função Objetivo
ROW_NUMBER() Numeração sequencial.
RANK() Ranking com saltos após empates.
DENSE_RANK() Ranking sem saltos após empates.
LAG() Acessa uma linha anterior.
LEAD() Acessa uma linha posterior.
SUM() OVER Soma dentro da janela.
AVG() OVER Média dentro da janela.
COUNT() OVER Contagem dentro da janela.

🧠 Mapa mental da aula

Window Function → calcula informações olhando para outras linhas sem eliminá-las.

OVER → define a janela utilizada pelo cálculo.

PARTITION BY → divide os registros em grupos.

ORDER BY → define a ordem dentro da janela.

ROW_NUMBER() → numeração sequencial.

RANK() → ranking com saltos após empates.

DENSE_RANK() → ranking sem saltos após empates.

LAG() → linha anterior.

LEAD() → linha posterior.

SUM() OVER → soma na janela.

Resumindo

Window Functions permitem realizar cálculos considerando várias linhas sem transformar todo o resultado em uma única linha por grupo.

OVER define a janela utilizada pela função.

PARTITION BY divide os dados em grupos independentes.

ROW_NUMBER(), RANK() e DENSE_RANK() são utilizadas principalmente para classificação e ordenação.

LAG() e LEAD() permitem comparar registros anteriores e posteriores.

Funções agregadas como SUM(), AVG() e COUNT() também podem ser utilizadas como Window Functions.
