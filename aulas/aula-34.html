🏪 Nosso cenário

Imagine que uma empresa possui milhões de registros de vendas armazenados em arquivos Parquet. 


vendas/
├── vendas_2024.parquet
├── vendas_2025.parquet
└── vendas_2026.parquet

Cada registro possui informações como: 


id
cliente_id
produto
categoria
cidade
quantidade
preco
data

Nosso objetivo é utilizar SQL para descobrir informações sobre essas vendas.

🔢 COUNT

O COUNT permite contar registros. 

SELECT
    COUNT(*) AS total_vendas
FROM 'vendas/*.parquet';

Podemos também contar valores de uma determinada coluna: 

SELECT
    COUNT(cliente_id) AS clientes
FROM 'vendas/*.parquet';
Atenção:

COUNT(*) conta os registros, enquanto COUNT(coluna) normalmente ignora valores NULL daquela coluna.

📐 AVG — Média

O AVG calcula a média de uma coluna numérica.

Por exemplo, podemos descobrir o preço médio dos produtos: 

SELECT
    AVG(preco) AS preco_medio
FROM 'vendas.parquet';

Também podemos calcular a quantidade média de produtos vendidos por registro: 

SELECT
    AVG(quantidade) AS quantidade_media
FROM 'vendas.parquet';

⬆️⬇️ MIN e MAX

Podemos descobrir o menor e o maior valor de uma coluna. 

SELECT
    MIN(preco) AS menor_preco,
    MAX(preco) AS maior_preco
FROM 'vendas.parquet';

Isso pode ser útil para identificar a faixa de preços existente nos dados.

🧮 Várias agregações na mesma consulta

Podemos utilizar várias funções de agregação ao mesmo tempo. 

SELECT

    COUNT(*) AS total_vendas,

    SUM(quantidade * preco) AS faturamento,

    AVG(preco) AS preco_medio,

    MIN(preco) AS menor_preco,

    MAX(preco) AS maior_preco

FROM 'vendas.parquet';

Uma única consulta pode gerar um pequeno resumo estatístico dos dados.

📊 GROUP BY

O GROUP BY permite realizar agregações separadamente para cada grupo.

Por exemplo, podemos calcular o faturamento por categoria: 

SELECT

    categoria,

    SUM(quantidade * preco) AS faturamento

FROM 'vendas.parquet'

GROUP BY categoria;

O resultado poderia ser: 


categoria        faturamento
----------------------------
Eletrônicos      12500000
Informática       9800000
Celulares        15300000
Móveis             7200000

🧩 Agrupando por mais de uma coluna

Também podemos agrupar por várias colunas.

Por exemplo: categoria + cidade. 

SELECT

    categoria,

    cidade,

    SUM(quantidade * preco) AS faturamento

FROM 'vendas.parquet'

GROUP BY
    categoria,
    cidade;

Agora teremos um resultado para cada combinação de categoria e cidade.

🔍 HAVING

Existe uma diferença importante entre WHERE e HAVING.

Comando Utilização
WHERE Filtra registros antes da agregação.
HAVING Filtra grupos depois da agregação.

Exemplo: queremos apenas categorias cujo faturamento seja maior que 10 milhões. 

SELECT

    categoria,

    SUM(quantidade * preco) AS faturamento

FROM 'vendas.parquet'

GROUP BY categoria

HAVING
    SUM(quantidade * preco) > 10000000;

🔥 WHERE + GROUP BY + HAVING

Podemos combinar as três operações.

Exemplo: analisar apenas vendas de São Paulo, agrupar por categoria e manter apenas categorias com faturamento superior a 1 milhão. 

SELECT

    categoria,

    SUM(quantidade * preco) AS faturamento

FROM 'vendas.parquet'

WHERE
    cidade = 'São Paulo'

GROUP BY
    categoria

HAVING
    SUM(quantidade * preco) > 1000000

ORDER BY
    faturamento DESC;

🧠 CASE

O CASE permite criar regras condicionais dentro de uma consulta SQL.

Imagine que queremos classificar os produtos pelo preço. 

SELECT

    produto,

    preco,

    CASE

        WHEN preco < 100
            THEN 'Barato'

        WHEN preco < 1000
            THEN 'Médio'

        ELSE
            'Caro'

    END AS faixa_preco

FROM 'vendas.parquet';

O SQL passa a criar uma nova classificação com base no valor do preço.

📊 CASE + agregação

O CASE também pode ser utilizado em análises.

Por exemplo, podemos classificar clientes de acordo com o valor de suas compras. 

SELECT

    cliente_id,

    SUM(quantidade * preco) AS total_compras,

    CASE

        WHEN
            SUM(quantidade * preco) >= 10000
            THEN 'VIP'

        WHEN
            SUM(quantidade * preco) >= 5000
            THEN 'Premium'

        ELSE
            'Regular'

    END AS categoria_cliente

FROM 'vendas.parquet'

GROUP BY
    cliente_id;

📅 Trabalhando com datas

Dados de vendas normalmente possuem uma coluna representando a data da operação.

Podemos filtrar um determinado período: 

SELECT *

FROM 'vendas.parquet'

WHERE
    data >= '2026-01-01'
    AND
    data < '2027-01-01';

Essa consulta representa as vendas realizadas durante o ano de 2026.

📆 Analisando por ano

Podemos extrair informações de uma data e agrupar os resultados. 

SELECT

    YEAR(data) AS ano,

    SUM(quantidade * preco) AS faturamento

FROM 'vendas.parquet'

GROUP BY
    YEAR(data)

ORDER BY
    ano;

📅 Analisando por mês

Podemos combinar ano e mês para criar uma análise temporal. 

SELECT

    YEAR(data) AS ano,

    MONTH(data) AS mes,

    SUM(quantidade * preco) AS faturamento

FROM 'vendas.parquet'

GROUP BY

    YEAR(data),

    MONTH(data)

ORDER BY

    ano,

    mes;
Esse tipo de consulta é muito comum em relatórios e dashboards.

📈 Criando métricas

Uma consulta SQL pode gerar várias métricas ao mesmo tempo. 

SELECT

    COUNT(*) AS vendas,

    SUM(quantidade) AS unidades,

    SUM(quantidade * preco) AS faturamento,

    AVG(preco) AS preco_medio,

    MIN(preco) AS menor_preco,

    MAX(preco) AS maior_preco

FROM 'vendas.parquet';

🏆 Ranking de produtos

Podemos descobrir quais produtos geraram mais faturamento. 

SELECT

    produto,

    SUM(quantidade * preco) AS faturamento

FROM 'vendas.parquet'

GROUP BY
    produto

ORDER BY
    faturamento DESC

LIMIT 10;

Assim podemos obter os 10 produtos com maior faturamento.

👥 Analisando clientes

Podemos aplicar a mesma lógica para clientes. 

SELECT

    cliente_id,

    COUNT(*) AS quantidade_compras,

    SUM(quantidade * preco) AS total_gasto

FROM 'vendas.parquet'

GROUP BY
    cliente_id

ORDER BY
    total_gasto DESC

LIMIT 10;

Agora conseguimos identificar os clientes que mais compraram.

🌎 Analisando regiões

Também podemos comparar o desempenho das diferentes cidades. 

SELECT

    cidade,

    COUNT(*) AS vendas,

    SUM(quantidade * preco) AS faturamento,

    AVG(quantidade * preco) AS ticket_medio

FROM 'vendas.parquet'

GROUP BY
    cidade

ORDER BY
    faturamento DESC;

O resultado pode ser utilizado posteriormente em gráficos e dashboards.

🧠 Entendendo a lógica da consulta

Uma consulta analítica normalmente segue uma lógica semelhante a esta: 


FROM
  ↓
WHERE
  ↓
GROUP BY
  ↓
HAVING
  ↓
SELECT
  ↓
ORDER BY
  ↓
LIMIT

FROM define a origem dos dados.

WHERE filtra registros.

GROUP BY cria grupos.

HAVING filtra os grupos.

SELECT define o resultado.

ORDER BY organiza o resultado.

LIMIT limita a quantidade retornada.

🚀 Uma análise completa

Vamos juntar vários conceitos.

Queremos descobrir as categorias que geraram mais de 1 milhão de faturamento em São Paulo. 

SELECT

    categoria,

    COUNT(*) AS vendas,

    SUM(quantidade) AS unidades,

    SUM(quantidade * preco) AS faturamento,

    AVG(preco) AS preco_medio

FROM 'vendas/*.parquet'

WHERE

    cidade = 'São Paulo'

GROUP BY

    categoria

HAVING

    SUM(quantidade * preco) > 1000000

ORDER BY

    faturamento DESC;

Essa consulta já se aproxima bastante de uma análise real de negócio.
