🔄 Relembrando o find()

Na aula anterior utilizamos: 

db.alunos.find()

Sem nenhum filtro, o MongoDB pode retornar os documentos da coleção.

Podemos adicionar um filtro: 

db.alunos.find({

    curso: "Computação"

})
A ideia principal:

O primeiro argumento do find() representa o filtro utilizado para selecionar os documentos.

🔎 Filtro por valor exato

Podemos procurar documentos que possuem um determinado valor. 

db.produtos.find({

    categoria: "Eletrônicos"

})

Nesse caso, estamos procurando produtos cuja categoria seja exatamente Eletrônicos.

Pense assim:

"Encontre os produtos onde categoria seja igual a Eletrônicos."

⚖️ Operadores de comparação

O MongoDB possui operadores especiais para realizar comparações.

Operador Significado
$gt Maior que
$gte Maior ou igual
$lt Menor que
$lte Menor ou igual
$eq Igual
$ne Diferente

📈 $gt — Maior que

O operador $gt significa greater than, ou seja, "maior que".

Vamos procurar produtos com preço maior que 1000: 

db.produtos.find({

    preco: {
        $gt: 1000
    }

})

Nesse exemplo serão encontrados produtos cujo preço seja superior a 1000.

📈 $gte — Maior ou igual

O operador $gte significa greater than or equal. 

db.produtos.find({

    preco: {
        $gte: 1000
    }

})

Agora produtos com preço exatamente igual a 1000 também serão considerados.

📉 $lt e $lte

Podemos fazer o contrário utilizando $lt e $lte.

Menor que 

db.produtos.find({

    preco: {
        $lt: 500
    }

})

Menor ou igual 

db.produtos.find({

    preco: {
        $lte: 500
    }

})

🚫 $ne — Diferente

O operador $ne significa not equal.

Podemos procurar produtos que não pertencem a uma determinada categoria. 

db.produtos.find({

    categoria: {
        $ne: "Eletrônicos"
    }

})

📋 $in — Entre várias opções

O operador $in permite procurar documentos cujo valor esteja dentro de uma lista de possibilidades. 

db.produtos.find({

    categoria: {
        $in: [
            "Eletrônicos",
            "Acessórios"
        ]
    }

})

Nesse caso, serão encontrados produtos que pertençam a qualquer uma das categorias informadas.

🚫 $nin — Fora de várias opções

O operador $nin faz o contrário do $in. 

db.produtos.find({

    categoria: {
        $nin: [
            "Eletrônicos",
            "Acessórios"
        ]
    }

})

Nesse exemplo procuramos documentos cuja categoria não esteja nessa lista.

🔗 Combinando condições

Podemos utilizar mais de uma condição no mesmo filtro.

Por exemplo: 

db.produtos.find({

    categoria: "Eletrônicos",

    preco: {
        $gt: 1000
    }

})

Aqui estamos procurando produtos que:

  • pertençam à categoria Eletrônicos;
  • tenham preço maior que 1000.
Na prática:

Quando várias condições são colocadas no mesmo documento de filtro, elas normalmente precisam ser satisfeitas simultaneamente.

🔀 $or — Uma condição ou outra

Quando queremos encontrar documentos que satisfaçam uma condição ou outra, podemos utilizar $or. 

db.produtos.find({

    $or: [

        {
            categoria: "Eletrônicos"
        },

        {
            preco: {
                $lt: 200
            }
        }

    ]

})

O resultado pode conter produtos que sejam eletrônicos ou produtos cujo preço seja menor que 200.

🚫 $not

O operador $not permite negar uma condição de comparação. 

db.produtos.find({

    preco: {
        $not: {
            $gt: 1000
        }
    }

})

Esse exemplo procura valores que não satisfaçam a condição de serem maiores que 1000.

👁️ Projeção — Escolhendo os campos

Imagine que um documento possui vários campos, mas queremos visualizar apenas alguns deles.

Podemos utilizar uma projeção. 

db.produtos.find(

    {},

    {
        nome: 1,
        preco: 1
    }

)

Nesse exemplo estamos solicitando que nome e preco sejam exibidos.

Regra geral:

O valor 1 indica inclusão do campo.

O valor 0 indica exclusão do campo.

👁️ Excluindo campos da projeção

Também podemos dizer quais campos não queremos visualizar. 

db.produtos.find(

    {},

    {
        estoque: 0
    }

)

Nesse caso, o campo estoque não será exibido na projeção.

Atenção:

Em uma projeção, não devemos misturar livremente inclusão e exclusão de campos. A principal exceção é o campo _id.

🆔 E o campo _id?

Por padrão, o MongoDB inclui o campo _id nos documentos retornados.

Podemos removê-lo da projeção: 

db.produtos.find(

    {},

    {
        _id: 0,
        nome: 1,
        preco: 1
    }

)

Assim teremos apenas os campos nome e preco no resultado.

↕️ Ordenando resultados

Podemos utilizar sort() para ordenar os resultados.

Ordem crescente 

db.produtos
    .find()
    .sort({
        preco: 1
    })

O valor 1 representa ordem crescente.

Ordem decrescente 

db.produtos
    .find()
    .sort({
        preco: -1
    })

O valor -1 representa ordem decrescente.

🔢 Limitando resultados

O método limit() permite definir quantos documentos queremos receber. 

db.produtos
    .find()
    .limit(2)

Nesse exemplo estamos solicitando no máximo dois documentos.

🔥 Combinando filtros, ordenação e limite

Podemos combinar diferentes métodos para construir consultas mais específicas. 

db.produtos
    .find({
        categoria: "Eletrônicos",
        preco: {
            $gt: 1000
        }
    })
    .sort({
        preco: -1
    })
    .limit(5)

Essa consulta:

  • procura produtos eletrônicos;
  • cujo preço seja maior que 1000;
  • ordena pelo preço do maior para o menor;
  • retorna no máximo cinco documentos.

🔢 Contando documentos

Podemos utilizar countDocuments() para contar quantos documentos correspondem a determinado filtro. 

db.produtos.countDocuments({

    categoria: "Eletrônicos"

})

O resultado será a quantidade de documentos que satisfazem a condição.

🔄 MongoDB × SQL

Como você já estudou SQL, podemos relacionar alguns conceitos para facilitar a compreensão.

SQL MongoDB
SELECT * find()
WHERE Filtro do find()
ORDER BY sort()
LIMIT limit()
COUNT() countDocuments()
Importante:

Essa comparação ajuda a entender conceitos semelhantes, mas MongoDB e bancos relacionais possuem modelos de dados diferentes.

🧪 Exemplo prático

Imagine uma loja virtual com milhares de produtos. Queremos encontrar os cinco produtos eletrônicos mais caros. 

db.produtos
    .find({
        categoria: "Eletrônicos"
    })
    .sort({
        preco: -1
    })
    .limit(5)

Observe como construímos a consulta passo a passo:

1️⃣ find()

Define quais documentos queremos encontrar.

2️⃣ sort()

Define a ordem dos resultados.

3️⃣ limit()

Limita a quantidade de documentos retornados.

⚠️ Erros comuns

❌ Confundir $gt com $gte

$gt significa maior que, enquanto $gte significa maior ou igual.

❌ Esquecer o filtro

Um find() sem filtro pode retornar muitos documentos.

❌ Confundir 1 e -1 no sort()

1 representa crescente e -1 representa decrescente.

❌ Misturar projeções incorretamente

Inclusão e exclusão de campos possuem regras específicas.

📝 Resumindo

find() é utilizado para consultar documentos.

Filtros permitem encontrar documentos que atendem a determinadas condições.

Operadores como $gt, $gte, $lt, $lte, $ne, $in e $nin permitem realizar comparações.

$or permite trabalhar com condições alternativas.

Projeções permitem controlar quais campos aparecem no resultado.

sort() organiza os resultados.

limit() limita a quantidade de documentos retornados.

countDocuments() permite contar documentos que correspondem a um filtro.
