Aggregation Pipeline

Aprenda a filtrar, transformar, agrupar, ordenar e analisar dados utilizando o sistema de agregação do MongoDB.

Agora vamos aprender uma ferramenta ainda mais poderosa: o Aggregation Pipeline.

🔄

Transformar

🧩 O que é Aggregation?

Aggregation é o mecanismo do MongoDB utilizado para processar documentos e produzir resultados derivados dos dados armazenados.

Podemos utilizar aggregation para:

  • filtrar documentos;
  • selecionar campos;
  • calcular valores;
  • agrupar documentos;
  • ordenar resultados;
  • limitar resultados;
  • combinar diferentes etapas de processamento.
Ideia principal:

Em vez de apenas buscar documentos, podemos construir um processo de transformação dos dados.

🚰 O que é um Pipeline?

A palavra pipeline pode ser entendida como uma sequência de etapas.

Os documentos passam por essas etapas e são transformados ao longo do processo. 

Documentos
    ↓
Etapa 1
    ↓
Etapa 2
    ↓
Etapa 3
    ↓
Resultado

No MongoDB, utilizamos o método: 

db.produtos.aggregate([
    // etapas
])
Pense em uma linha de produção:

cada etapa recebe o resultado da etapa anterior e realiza algum processamento.

Vamos trabalhar com uma coleção chamada vendas.

🔎 $match — Filtrando documentos

O estágio $match é utilizado para selecionar documentos que atendem a determinadas condições. 

db.vendas.aggregate([

    {
        $match: {
            categoria: "Eletrônicos"
        }
    }

])

Essa consulta mantém apenas os documentos cuja categoria seja "Eletrônicos".

Relação com o find():

$match possui uma função semelhante ao filtro utilizado no find().

👁️ $project — Escolhendo e transformando campos

O estágio $project permite controlar quais campos estarão no resultado. 

db.vendas.aggregate([

    {
        $project: {
            produto: 1,
            categoria: 1,
            preco: 1
        }
    }

])

Podemos também criar novos campos durante o processamento. 

db.vendas.aggregate([

    {
        $project: {

            produto: 1,

            total: {
                $multiply: [
                    "$quantidade",
                    "$preco"
                ]
            }

        }
    }

])

Aqui estamos calculando o valor total da venda.

🧮 Operadores de cálculo

O aggregation framework possui operadores que permitem realizar cálculos.

Operador Função
$add Soma valores.
$subtract Subtrai valores.
$multiply Multiplica valores.
$divide Divide valores.
$mod Retorna o resto da divisão.

📊 $group — Agrupando documentos

O estágio $group permite agrupar documentos de acordo com determinado valor.

Por exemplo, podemos agrupar vendas por categoria: 

db.vendas.aggregate([

    {
        $group: {

            _id: "$categoria"

        }
    }

])

O campo _id representa a chave utilizada para definir cada grupo.

Resultado conceitual:

Um grupo para "Eletrônicos" e outro grupo para "Acessórios".

➕ $sum

O operador $sum permite somar valores.

Podemos contar quantos documentos existem em cada categoria: 

db.vendas.aggregate([

    {
        $group: {

            _id: "$categoria",

            quantidadeVendas: {
                $sum: 1
            }

        }
    }

])

O $sum: 1 adiciona 1 para cada documento que pertence ao grupo.

💰 Somando valores

Também podemos somar valores armazenados em um campo. 

db.vendas.aggregate([

    {
        $group: {

            _id: "$categoria",

            total: {
                $sum: "$preco"
            }

        }
    }

])

Nesse caso, o MongoDB soma os valores de preco de cada grupo.

📐 $avg — Média

O operador $avg calcula uma média. 

db.vendas.aggregate([

    {
        $group: {

            _id: "$categoria",

            precoMedio: {
                $avg: "$preco"
            }

        }
    }

])

O resultado apresenta o preço médio por categoria.

📈 $min e $max

Também podemos encontrar o menor e o maior valor dentro de cada grupo. 

db.vendas.aggregate([

    {
        $group: {

            _id: "$categoria",

            menorPreco: {
                $min: "$preco"
            },

            maiorPreco: {
                $max: "$preco"
            }

        }
    }

])

↕️ $sort — Ordenando resultados

O estágio $sort permite ordenar os documentos produzidos pelo pipeline. 

db.vendas.aggregate([

    {
        $sort: {
            preco: -1
        }
    }

])

O valor 1 representa ordem crescente.

O valor -1 representa ordem decrescente.

🔢 $limit

O estágio $limit limita a quantidade de documentos que continuam no pipeline. 

db.vendas.aggregate([

    {
        $sort: {
            preco: -1
        }
    },

    {
        $limit: 3
    }

])

Primeiro os documentos são ordenados e depois somente os três primeiros continuam.

⏭️ $skip

O estágio $skip ignora uma quantidade determinada de documentos. 

db.vendas.aggregate([

    {
        $skip: 5
    }

])

Nesse exemplo, os cinco primeiros documentos são ignorados.

Paginação:

Combinações entre $skip e $limit podem ser utilizadas para implementar paginação.

🔥 Combinando vários estágios

O verdadeiro poder do aggregation pipeline aparece quando combinamos diferentes etapas.

Imagine que queremos encontrar as vendas de eletrônicos, calcular o total de cada venda, ordenar pelo valor e mostrar somente as três maiores. 

db.vendas.aggregate([

    {
        $match: {
            categoria: "Eletrônicos"
        }
    },

    {
        $project: {

            produto: 1,

            total: {
                $multiply: [
                    "$quantidade",
                    "$preco"
                ]
            }

        }
    },

    {
        $sort: {
            total: -1
        }
    },

    {
        $limit: 3
    }

])

Observe o fluxo:

1️⃣ $match

Filtra os eletrônicos.

2️⃣ $project

Calcula o valor total.

3️⃣ $sort

Ordena do maior para o menor.

4️⃣ $limit

Mantém somente três resultados.

📊 Criando um relatório por categoria

Agora vamos criar um relatório que mostra:

  • quantidade de vendas;
  • preço médio;
  • menor preço;
  • maior preço. 
db.vendas.aggregate([

    {
        $group: {

            _id: "$categoria",

            quantidadeVendas: {
                $sum: 1
            },

            precoMedio: {
                $avg: "$preco"
            },

            menorPreco: {
                $min: "$preco"
            },

            maiorPreco: {
                $max: "$preco"
            }

        }
    },

    {
        $sort: {
            quantidadeVendas: -1
        }
    }

])

Agora estamos utilizando o MongoDB para produzir informações agregadas, e não apenas buscar documentos.

🔢 Contando documentos com $group

Outra possibilidade é simplesmente contar quantos documentos existem em cada categoria. 

db.vendas.aggregate([

    {
        $group: {

            _id: "$categoria",

            total: {
                $sum: 1
            }

        }
    }

])

O resultado será algo semelhante a: 

{
    _id: "Eletrônicos",
    total: 2
}

{
    _id: "Acessórios",
    total: 2
}

📋 $unwind — Trabalhando com arrays

O estágio $unwind é utilizado para separar elementos de um array em documentos individuais durante o processamento.

Imagine: 

{
    cliente: "Ana",

    produtos: [
        "Notebook",
        "Mouse",
        "Teclado"
    ]
}

Podemos utilizar: 

db.pedidos.aggregate([

    {
        $unwind: "$produtos"
    }

])

Cada elemento do array passa a ser processado separadamente.

Ideia:

Um documento com três elementos no array pode gerar três documentos intermediários no pipeline.

🧩 $replaceWith

O estágio $replaceWith permite substituir o documento atual por uma nova expressão.

Por exemplo, se temos: 

{
    nome: "Ana",

    endereco: {
        cidade: "Rio de Janeiro",
        estado: "RJ"
    }
}

Podemos trabalhar diretamente com o conteúdo de endereco: 

db.pessoas.aggregate([

    {
        $replaceWith: "$endereco"
    }

])

O documento resultante terá como estrutura principal o conteúdo do campo endereco.

🔢 $count

O estágio $count permite contar quantos documentos chegaram até determinado ponto do pipeline. 

db.vendas.aggregate([

    {
        $match: {
            categoria: "Eletrônicos"
        }
    },

    {
        $count: "total"
    }

])

Primeiro filtramos os documentos e depois contamos quantos permaneceram.

🧠 Como pensar em um Aggregation Pipeline?

Antes de escrever o código, pense no problema em etapas.

1️⃣ O que preciso?

Defina qual informação deseja obter.

2️⃣ O que devo filtrar?

Pense no $match.

3️⃣ Preciso calcular?

Pense no $project ou nos operadores de agregação.

4️⃣ Preciso agrupar?

Pense no $group.

5️⃣ Preciso ordenar?

Utilize $sort.

6️⃣ Preciso limitar?

Utilize $limit.

🔄 Aggregation × SQL

Algumas operações do aggregation pipeline possuem conceitos semelhantes aos encontrados no SQL.

SQL MongoDB
WHERE $match
SELECT $project
GROUP BY $group
ORDER BY $sort
LIMIT $limit
Importante:

Essa tabela é uma comparação conceitual. Aggregation Pipeline e SQL possuem diferenças importantes de sintaxe e funcionamento.

📝 Resumindo

O Aggregation Pipeline permite processar documentos em várias etapas.

$match filtra documentos.

$project seleciona e transforma campos.

$group agrupa documentos e permite realizar cálculos.

$sum, $avg, $min e $max permitem realizar diferentes agregações.

$sort ordena os resultados.

$limit limita a quantidade de documentos.

$skip permite ignorar documentos, sendo útil em determinados cenários de paginação.

$unwind permite trabalhar com elementos de arrays individualmente dentro do pipeline.
