O que é SQL?

SQL significa Structured Query Language, ou Linguagem de Consulta Estruturada.

SQL é uma linguagem utilizada para trabalhar principalmente com bancos de dados relacionais.

Importante:

SQL não é um banco de dados.

SQL também não é um SGBD.

SQL é uma linguagem utilizada para definir, consultar e manipular dados e estruturas em sistemas de banco de dados que suportam SQL.

PostgreSQL e MySQL, por exemplo, são SGBDs que utilizam SQL como uma de suas principais formas de interação com bancos de dados relacionais.

SQL, SGBD e banco de dados

É importante não confundir esses conceitos.

Conceito O que é? Exemplo
Banco de dados Conjunto organizado de dados armazenados. Banco da loja
SGBD Software que gerencia bancos de dados. PostgreSQL
SQL Linguagem utilizada para trabalhar com dados e estruturas. SELECT, INSERT, CREATE TABLE
Aplicação Software utilizado pelo usuário ou por outros sistemas. Loja virtual

Principais categorias de comandos SQL

Os comandos SQL podem ser classificados de diferentes maneiras.

DDL

Data Definition Language

Comandos relacionados à definição da estrutura do banco.

Exemplos: CREATE, ALTER e DROP.

DML

Data Manipulation Language

Comandos utilizados para inserir, alterar e excluir dados.

Exemplos: INSERT, UPDATE e DELETE.

DQL

Data Query Language

Comandos utilizados para consultar dados.

Principal exemplo: SELECT.

DCL

Data Control Language

Comandos relacionados ao controle de permissões e acesso.

Exemplos: GRANT e REVOKE.

Nesta aula:

Nosso foco será principalmente em CREATE TABLE, INSERT e SELECT.

Criando um banco de dados

Alguns SGBDs permitem criar um banco de dados utilizando o comando CREATE DATABASE. 

CREATE DATABASE loja;

Nesse exemplo, estamos solicitando ao SGBD a criação de um banco de dados chamado loja.

Atenção:

A forma de criar e selecionar bancos de dados pode variar de acordo com o SGBD.

Por isso, detalhes específicos de PostgreSQL, MySQL ou outros SGBDs serão estudados conforme avançarmos no curso.

Criando uma tabela

Depois de termos um banco de dados, podemos criar tabelas dentro dele.

Vamos criar uma tabela para armazenar clientes: 

CREATE TABLE clientes (

    id INTEGER PRIMARY KEY,

    nome VARCHAR(100),

    email VARCHAR(150)

);

Esse comando define uma tabela chamada clientes.

Elemento Significado
CREATE TABLE Cria uma tabela.
clientes Nome da tabela.
id Coluna identificadora.
INTEGER Tipo de dado inteiro.
PRIMARY KEY Define a chave primária.
VARCHAR(100) Texto com tamanho máximo especificado.

Tipos de dados

Cada coluna precisa representar um determinado tipo de informação.

INTEGER

Números inteiros

Utilizado para valores inteiros, como IDs e quantidades.

VARCHAR

Texto

Utilizado para textos com tamanho definido.

DATE

Data

Utilizado para armazenar datas.

BOOLEAN

Verdadeiro ou falso

Utilizado para valores booleanos.

Os tipos disponíveis e seus comportamentos podem variar conforme o SGBD.

Inserindo dados

Depois de criar uma tabela, podemos adicionar registros utilizando INSERT. 

INSERT INTO clientes
    (id, nome, email)

VALUES
    (1, 'Ana Silva', 'ana@email.com');

Podemos inserir outro cliente: 

INSERT INTO clientes
    (id, nome, email)

VALUES
    (2, 'João Santos', 'joao@email.com');
O que aconteceu?

Criamos um novo registro na tabela clientes.

Visualizando os dados

Agora podemos utilizar SELECT para consultar os registros. 

SELECT *
FROM clientes;

O símbolo * significa que queremos selecionar todas as colunas.

O resultado poderia ser semelhante a:

id nome email
1 Ana Silva ana@email.com
2 João Santos joao@email.com

Escolhendo as colunas

Não precisamos consultar todas as colunas.

Podemos escolher apenas as informações desejadas: 

SELECT nome, email
FROM clientes;

Nesse caso, o resultado terá somente:

nome

email

Filtrando resultados com WHERE

O comando WHERE permite definir uma condição para a consulta. 

SELECT *
FROM clientes
WHERE id = 1;

Essa consulta procura o cliente cujo id seja igual a 1.

Também podemos filtrar pelo nome: 

SELECT *
FROM clientes
WHERE nome = 'Ana Silva';

Operadores básicos

Podemos utilizar operadores para construir condições.

Operador Significado Exemplo
= Igual id = 1
> Maior que preco > 100
< Menor que preco < 100
>= Maior ou igual idade >= 18
<= Menor ou igual preco <= 50
<> Diferente status <> 'cancelado'

Atualizando dados

Para alterar um registro existente, utilizamos UPDATE. 

UPDATE clientes
SET email = 'ana.silva@email.com'
WHERE id = 1;
Cuidado com o WHERE!

O WHERE define quais registros serão alterados.

Um UPDATE sem uma condição adequada pode alterar muitos registros de uma só vez.

Excluindo dados

Para excluir registros, utilizamos DELETE. 

DELETE FROM clientes
WHERE id = 2;
Atenção!

Assim como no UPDATE, o WHERE é extremamente importante para controlar quais registros serão excluídos.

Vamos juntar os conceitos aprendidos. 

CREATE TABLE produtos (

    (id, nome, preco)

    (1, 'Notebook', 3500.00);

    (id, nome, preco)

    (2, 'Mouse', 80.00);


SELECT *
FROM produtos;

Nesse exemplo:

  • criamos uma tabela;
  • definimos suas colunas;
  • definimos uma chave primária;
  • inserimos dois produtos;
  • consultamos os dados.

Uma aplicação pode enviar comandos ao SGBD. O SGBD interpreta esses comandos e realiza as operações solicitadas sobre os dados.

Em uma aplicação real, normalmente não digitamos SQL diretamente toda vez que o usuário realiza uma ação. O código da aplicação pode gerar ou executar consultas SQL por meio de uma biblioteca, driver ou outra camada de acesso a dados.

🧪 Exercício 1 — Criando uma tabela

Crie uma tabela chamada alunos contendo:

  • id;
  • nome;
  • email;
  • idade.

Uma possível solução seria: 

CREATE TABLE alunos (

    id INTEGER PRIMARY KEY,

    nome VARCHAR(100),

    email VARCHAR(150),

    idade INTEGER

);

🧪 Exercício 2 — Inserindo alunos

Insira pelo menos três alunos.

Exemplo: 

INSERT INTO alunos
    (id, nome, email, idade)

VALUES
    (1, 'Ana', 'ana@email.com', 20);


INSERT INTO alunos
    (id, nome, email, idade)

VALUES
    (2, 'João', 'joao@email.com', 22);


INSERT INTO alunos
    (id, nome, email, idade)

VALUES
    (3, 'Maria', 'maria@email.com', 19);

🧪 Exercício 3 — Consultando

Escreva uma consulta que mostre todos os alunos. 

SELECT *
FROM alunos;

Agora consulte somente o nome e o e-mail: 

SELECT nome, email
FROM alunos;

Por fim, consulte somente alunos com idade maior ou igual a 20 anos: 

SELECT *
FROM alunos
WHERE idade >= 20;
