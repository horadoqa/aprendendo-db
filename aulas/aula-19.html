AULA 19 • MONGODB

CRUD no MongoDB

Aprenda a criar, consultar, atualizar e excluir documentos utilizando as operações fundamentais do MongoDB.

🎯 Objetivos da aula

Nesta aula vamos começar a manipular dados de verdade no MongoDB utilizando as operações fundamentais do CRUD.

🟢

Create

Inserir novos documentos em uma coleção.

🔵

Read

Consultar documentos armazenados.

🟡

Update

Alterar documentos existentes.

🔴

Delete

Excluir documentos.

🔄 Relembrando

Nas aulas anteriores aprendemos que o MongoDB é um SGBD NoSQL orientado a documentos.

Os dados são armazenados em documentos que ficam organizados dentro de coleções. 

MongoDB
   │
   └── Banco de dados
          │
          └── Coleção
                 │
                 ├── Documento
                 ├── Documento
                 └── Documento
Agora vamos manipular esses documentos.

Para isso utilizaremos o CRUD.

🔄 O que é CRUD?

CRUD é uma sigla formada pelas quatro operações fundamentais realizadas sobre dados:

Operação Significado Objetivo
Create Criar Inserir novos dados
Read Ler Consultar dados
Update Atualizar Modificar dados existentes
Delete Excluir Remover dados

💻 Onde podemos executar os comandos?

Os comandos desta aula podem ser executados utilizando ferramentas como o mongosh ou o ambiente de consulta do MongoDB Compass.

Também é possível executar operações MongoDB através de aplicações utilizando drivers oficiais da linguagem escolhida.

Importante:

Os exemplos desta aula utilizam a sintaxe do shell do MongoDB.

Não estamos utilizando SQL.

🗄️ Selecionando um banco de dados

Antes de trabalhar com uma coleção, podemos selecionar o banco de dados que desejamos utilizar. 

use escola

Nesse exemplo, estamos trabalhando com um banco chamado escola.

Uma observação importante:

O comando use seleciona o banco para a sessão. O banco pode ser criado de forma efetiva quando dados forem armazenados nele.

🗂️ Trabalhando com uma coleção

Vamos imaginar que nosso banco possui uma coleção chamada alunos. 

db.alunos

O objeto db representa o banco de dados atualmente selecionado.

Portanto: 

db.alunos

        │
        └── coleção "alunos"

🟢 CREATE — Criando documentos

A primeira operação do CRUD é o Create.

No MongoDB podemos utilizar insertOne() para inserir um documento. 

db.alunos.insertOne({

    nome: "Ana Silva",

    idade: 20,

    curso: "Sistemas de Informação"

})

Esse comando insere um documento na coleção alunos.

O MongoDB pode gerar automaticamente o _id.

Caso não forneçamos um campo _id, o MongoDB normalmente gera um identificador único para o documento.

🟢 Inserindo vários documentos

Quando precisamos inserir vários documentos de uma vez, podemos utilizar insertMany(). 

db.alunos.insertMany([

    {
        nome: "João Santos",
        idade: 22,
        curso: "Engenharia"
    },

    {
        nome: "Maria Oliveira",
        idade: 21,
        curso: "Computação"
    },

    {
        nome: "Carlos Souza",
        idade: 24,
        curso: "Sistemas de Informação"
    }

])

Agora três documentos foram enviados para a coleção.

🔵 READ — Consultando documentos

A segunda operação do CRUD é o Read.

Para consultar documentos podemos utilizar find(). 

db.alunos.find()

Esse comando solicita os documentos encontrados na coleção alunos.

Leia como uma pergunta:

"MongoDB, mostre os documentos da coleção alunos."

🔎 Consultando um único documento

Quando queremos encontrar apenas um documento, podemos utilizar findOne(). 

db.alunos.findOne({

    nome: "Ana Silva"

})

O MongoDB procura um documento que corresponda ao filtro informado.

🔍 Consultando com filtro

O find() também pode receber um filtro. 

db.alunos.find({

    curso: "Computação"

})

Nesse exemplo estamos procurando alunos cujo campo curso possui o valor Computação.

Estrutura: 
db.colecao.find({

    campo: valor

})

🟡 UPDATE — Atualizando documentos

A terceira operação do CRUD é o Update.

Para atualizar um documento podemos utilizar updateOne(). 

db.alunos.updateOne(

    {
        nome: "Ana Silva"
    },

    {
        $set: {
            idade: 21
        }
    }

)

Nesse exemplo estamos procurando a aluna Ana Silva e alterando sua idade para 21.

🛠️ O operador $set

O operador $set é utilizado para definir ou alterar o valor de um campo. 

db.alunos.updateOne(

    { nome: "João Santos" },

    {
        $set: {
            curso: "Ciência da Computação"
        }
    }

)

O campo curso será atualizado.

Uma ideia importante:

O filtro determina qual documento será encontrado.

O operador de atualização determina o que será alterado.

🟡 Atualizando vários documentos

Quando precisamos atualizar vários documentos, podemos utilizar updateMany(). 

db.alunos.updateMany(

    {
        curso: "Computação"
    },

    {
        $set: {
            ativo: true
        }
    }

)

Nesse exemplo, todos os documentos que possuem curso: "Computação" receberão o campo ativo com valor true.

Cuidado!

Operações como updateMany() podem alterar muitos documentos de uma vez.

Sempre confira o filtro antes de executar uma alteração em dados importantes.

🔴 DELETE — Excluindo documentos

A quarta operação do CRUD é o Delete.

Para excluir um documento podemos utilizar deleteOne(). 

db.alunos.deleteOne({

    nome: "Carlos Souza"

})

O MongoDB procura um documento correspondente ao filtro e remove um documento.

⚠️ Atenção:

Exclusão de dados pode ser irreversível. Tenha cuidado principalmente em ambientes que contenham dados importantes.

🔴 Excluindo vários documentos

Também existe o método deleteMany(). 

db.alunos.deleteMany({

    ativo: false

})

Nesse exemplo, os documentos que correspondem ao filtro serão removidos.

Cuidado redobrado:

Um filtro muito amplo pode remover uma quantidade grande de documentos.

🧠 O CRUD completo

CRUD MongoDB Exemplo
Create insertOne() Inserir documento
Read find() Consultar documentos
Update updateOne() Alterar documento
Delete deleteOne() Excluir documento

🔥 Um exemplo completo

Vamos imaginar que acabamos de criar uma coleção chamada produtos.

1. Criar 

db.produtos.insertOne({

    nome: "Notebook",

    preco: 3500,

    estoque: 10

})

2. Consultar 

db.produtos.find()

3. Atualizar 

db.produtos.updateOne(

    {
        nome: "Notebook"
    },

    {
        $set: {
            preco: 3300
        }
    }

)

4. Excluir 

db.produtos.deleteOne({

    nome: "Notebook"

})
Perceba o ciclo:

Criamos → consultamos → alteramos → excluímos.

Esse é o ciclo básico de manipulação de dados conhecido como CRUD.

🔄 MongoDB × SQL

Como você já estudou SQL, podemos comparar alguns conceitos para facilitar a transição.

Operação SQL MongoDB
Criar INSERT insertOne()
Consultar SELECT find()
Atualizar UPDATE updateOne()
Excluir DELETE deleteOne()
Importante:

Essa tabela é uma comparação de operações, não significa que SQL e MongoDB funcionem da mesma maneira internamente.

⚠️ Erros comuns

❌ Confundir find() com findOne()

find() pode retornar vários documentos, enquanto findOne() retorna um documento que corresponda ao filtro.

❌ Atualizar sem filtro adequado

Sempre confira o filtro antes de executar uma atualização.

❌ Excluir sem conferir o filtro

Uma operação de exclusão pode remover dados importantes.

❌ Confundir $set com substituição

$set altera campos específicos. Substituir um documento inteiro é outra operação.

📝 Resumindo

Create representa a criação de novos documentos.

Read representa a consulta dos documentos.

Update representa a alteração de documentos existentes.

Delete representa a exclusão de documentos.

No MongoDB, operações comuns incluem insertOne(), insertMany(), find(), findOne(), updateOne(), updateMany(), deleteOne() e deleteMany().

Filtros são fundamentais para determinar quais documentos serão encontrados, atualizados ou excluídos.
