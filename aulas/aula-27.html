🔎 1. $match — filtrando documentos

O $match é utilizado para selecionar somente os documentos que atendem a uma determinada condição.

Por exemplo, queremos apenas as vendas concluídas: 

db.vendas.aggregate([

    {
        $match: {
            status: "concluida"
        }
    }

])

O MongoDB continuará o pipeline somente com os documentos cujo campo status seja "concluida".

Pense no $match como um filtro.

Ele reduz o conjunto de documentos que será processado pelas próximas etapas.

🔢 2. $match com operadores de comparação

Podemos utilizar operadores para fazer comparações.

Operador Significado
$gt Maior que
$gte Maior ou igual
$lt Menor que
$lte Menor ou igual
$eq Igual
$ne Diferente

Exemplo

Encontrar vendas com valor superior a R$ 1.000: 

db.vendas.aggregate([

    {
        $match: {

            valor: {
                $gt: 1000
            }

        }
    }

])

🧩 3. Combinando condições

Podemos combinar diferentes condições dentro de um mesmo filtro.

Por exemplo:

  • Venda concluída
  • Valor superior a R$ 1.000 
db.vendas.aggregate([

    {
        $match: {

            status: "concluida",

            valor: {
                $gt: 1000
            }

        }
    }

])

Nesse caso, o documento precisa atender às duas condições.

🔀 4. Utilizando $or

O operador $or permite trabalhar com condições alternativas.

Queremos encontrar vendas realizadas no Rio de Janeiro ou em São Paulo: 

db.vendas.aggregate([

    {
        $match: {

            $or: [

                {
                    cidade: "Rio de Janeiro"
                },

                {
                    cidade: "São Paulo"
                }

            ]

        }
    }

])

📋 5. $project — escolhendo os campos

O $project permite controlar quais campos serão apresentados no resultado.

Imagine que queremos mostrar somente:

  • Cliente
  • Produto
  • Valor 
db.vendas.aggregate([

    {
        $project: {

            cliente: 1,

            produto: 1,

            valor: 1

        }
    }

])
1 significa incluir o campo.

Podemos utilizar o 0 para excluir campos, respeitando as regras de projeção do MongoDB.

🧮 6. Criando cálculos com $project

O $project também pode criar novos campos calculados.

Imagine que o campo valor representa o preço unitário.

Podemos calcular o valor total da venda: 

db.vendas.aggregate([

    {
        $project: {

            cliente: 1,

            produto: 1,

            quantidade: 1,

            valor: 1,

            total: {
                $multiply: [
                    "$quantidade",
                    "$valor"
                ]
            }

        }
    }

])

O operador $multiply realiza uma multiplicação.

➕ 7. $set — adicionando campos

O estágio $set pode ser utilizado para adicionar ou modificar campos durante o pipeline. 

db.vendas.aggregate([

    {
        $set: {

            total: {
                $multiply: [
                    "$quantidade",
                    "$valor"
                ]
            }

        }
    }

])

O documento continuará com seus campos originais, mas terá também o campo total.

↕️ 8. $sort — ordenando resultados

O $sort permite organizar os documentos.

Para ordenar do menor para o maior: 

db.vendas.aggregate([

    {
        $sort: {
            valor: 1
        }
    }

])

Para ordenar do maior para o menor: 

db.vendas.aggregate([

    {
        $sort: {
            valor: -1
        }
    }

])

1

Crescente.

-1

Decrescente.

✋ 9. $limit — limitando resultados

O $limit limita a quantidade de documentos que continuará no pipeline.

Por exemplo, queremos somente as três maiores vendas: 

db.vendas.aggregate([

    {
        $sort: {
            valor: -1
        }
    },

    {
        $limit: 3
    }

])
$sort + $limit

Essa combinação é bastante útil para criar rankings, como "os 5 produtos mais vendidos" ou "os 10 maiores pedidos".

📊 10. $group — agrupando documentos

O $group permite transformar vários documentos em grupos e realizar cálculos sobre eles.

Por exemplo, queremos saber quanto foi vendido em cada cidade. 

db.vendas.aggregate([

    {
        $group: {

            _id: "$cidade",

            totalVendas: {
                $sum: "$valor"
            }

        }
    }

])

O campo _id determina como os documentos serão agrupados.

➕ 11. $sum — somando valores

O $sum permite calcular uma soma. 

db.vendas.aggregate([

    {
        $group: {

            _id: "$categoria",

            faturamento: {
                $sum: "$valor"
            }

        }
    }

])

O resultado será um grupo para cada categoria.

🔢 12. Contando documentos com $sum

Uma técnica comum é utilizar $sum: 1 para contar documentos. 

db.vendas.aggregate([

    {
        $group: {

            _id: "$cidade",

            quantidadeVendas: {
                $sum: 1
            }

        }
    }

])

Para cada documento pertencente ao grupo, o MongoDB adiciona 1.

📐 13. $avg — calculando médias

O operador $avg calcula a média dos valores. 

db.vendas.aggregate([

    {
        $group: {

            _id: "$categoria",

            valorMedio: {
                $avg: "$valor"
            }

        }
    }

])

Podemos utilizar isso para descobrir, por exemplo, o valor médio das vendas por categoria.

📈 14. $min e $max

Também podemos encontrar o menor e o maior valor dentro de cada grupo. 

db.vendas.aggregate([

    {
        $group: {

            _id: "$categoria",

            menorVenda: {
                $min: "$valor"
            },

            maiorVenda: {
                $max: "$valor"
            }

        }
    }

])

🔢 15. Contando documentos após um filtro

Podemos combinar $match e $group.

Exemplo: descobrir quantas vendas concluídas existem. 

db.vendas.aggregate([

    {
        $match: {
            status: "concluida"
        }
    },

    {
        $group: {

            _id: null,

            quantidade: {
                $sum: 1
            }

        }
    }

])

🔥 16. Criando um Pipeline completo

Agora vamos combinar vários operadores.

O objetivo será:

  1. Considerar somente vendas concluídas.
  2. Calcular o valor total de cada venda.
  3. Agrupar as vendas por cidade.
  4. Calcular o faturamento de cada cidade.
  5. Ordenar as cidades pelo maior faturamento. 
db.vendas.aggregate([

    {
        $match: {
            status: "concluida"
        }
    },

    {
        $set: {

            total: {
                $multiply: [
                    "$quantidade",
                    "$valor"
                ]
            }

        }
    },

    {
        $group: {

            _id: "$cidade",

            faturamento: {
                $sum: "$total"
            }

        }
    },

    {
        $sort: {
            faturamento: -1
        }
    }

])
Observe a sequência:

$match → $set → $group → $sort

Cada etapa recebe o resultado produzido pela etapa anterior.

🔗 17. $lookup — relacionando coleções

O $lookup permite combinar documentos de coleções diferentes durante uma agregação.

Imagine duas coleções: 

clientes

{
    _id: 101,
    nome: "Ana"
}

E: 

vendas

{
    clienteId: 101,
    produto: "Notebook",
    valor: 4500
}

Podemos utilizar: 

db.vendas.aggregate([

    {
        $lookup: {

            from: "clientes",

            localField: "clienteId",

            foreignField: "_id",

            as: "cliente"

        }
    }

])

O resultado incluirá um novo campo chamado cliente contendo os documentos correspondentes encontrados na coleção clientes.

📦 18. $unwind — trabalhando com arrays

O $unwind é utilizado quando temos um campo que contém um array.

Imagine um pedido: 

{
    pedido: 1001,

    itens: [

        {
            produto: "Notebook",
            quantidade: 1
        },

        {
            produto: "Mouse",
            quantidade: 2
        },

        {
            produto: "Teclado",
            quantidade: 1
        }

    ]
}

Podemos utilizar: 

db.pedidos.aggregate([

    {
        $unwind: "$itens"
    }

])

Cada elemento do array será processado separadamente pelas próximas etapas do pipeline.

🛍️ 19. $unwind + $group

Podemos combinar os dois operadores para descobrir quais produtos foram mais vendidos. 

db.pedidos.aggregate([

    {
        $unwind: "$itens"
    },

    {
        $group: {

            _id: "$itens.produto",

            quantidadeVendida: {
                $sum: "$itens.quantidade"
            }

        }
    },

    {
        $sort: {
            quantidadeVendida: -1
        }
    }

])

Esse tipo de consulta é muito comum em relatórios de vendas.

🏆 20. Criando um ranking

Uma aplicação pode precisar mostrar os produtos mais vendidos.

Podemos combinar:

  • $unwind
  • $group
  • $sort
  • $limit 
db.pedidos.aggregate([

    {
        $unwind: "$itens"
    },

    {
        $group: {

            _id: "$itens.produto",

            quantidade: {
                $sum: "$itens.quantidade"
            }

        }
    },

    {
        $sort: {
            quantidade: -1
        }
    },

    {
        $limit: 5
    }

])
Resultado:

Os cinco produtos com maior quantidade vendida.

⚠️ 21. A ordem dos estágios importa

Um dos pontos mais importantes do Aggregation Pipeline é entender que cada estágio trabalha com o resultado do estágio anterior.

Por exemplo: 

$match
   ↓
$group
   ↓
$sort

não é necessariamente equivalente a: 

$group
   ↓
$match
   ↓
$sort
Regra prática:

Quando possível, filtre os documentos desnecessários nas primeiras etapas do pipeline.

📊 22. O Aggregation Pipeline em aplicações reais

O Aggregation Pipeline é especialmente útil para gerar informações que não estão armazenadas diretamente em um único documento.

📝 Resumindo

A Aggregation Pipeline permite transformar e analisar documentos utilizando uma sequência de etapas.

O $match filtra documentos.

O $project controla os campos retornados e pode criar expressões.

O $set permite adicionar ou modificar campos durante o processamento.

O $group permite criar agrupamentos e calcular estatísticas.

O $sort organiza os resultados.

O $limit limita a quantidade de documentos.

O $lookup permite combinar dados de diferentes coleções.

O $unwind permite trabalhar individualmente com elementos de arrays.

Combinando esses operadores, podemos construir consultas capazes de gerar relatórios e métricas complexas a partir dos documentos armazenados.
