Consultas Avançadas no MongoDB

Aprenda a consultar arrays, documentos aninhados e combinar condições para trabalhar com estruturas de dados mais complexas.

🎯 Objetivos da aula

Até agora aprendemos a consultar documentos simples. Porém, uma das grandes características do MongoDB é permitir que um documento contenha estruturas mais complexas.

Nesta aula vamos aprender a consultar:

📋

Arrays

Listas de valores armazenadas dentro de documentos.

🧩

Documentos aninhados

Objetos armazenados dentro de outros documentos.

Operadores lógicos

Combinação de diferentes condições.

Consultas complexas

Construção de filtros mais específicos.

🔄 Relembrando o MongoDB

No MongoDB, os dados são armazenados como documentos BSON, que possuem uma estrutura semelhante ao JSON.

Um documento simples pode ser: 

{
    nome: "Ana",
    idade: 25,
    cidade: "Rio de Janeiro"
}

Mas os documentos também podem possuir arrays e outros objetos: 

{
    nome: "Ana",

    idade: 25,

    habilidades: [
        "JavaScript",
        "SQL",
        "MongoDB"
    ],

    endereco: {
        cidade: "Rio de Janeiro",
        estado: "RJ"
    }
}
Esse é um dos pontos importantes do MongoDB:

um documento pode representar uma estrutura de dados rica e hierárquica.

📋 O que são Arrays?

Um array é uma coleção ordenada de valores.

Por exemplo: 

{
    nome: "Carlos",

    habilidades: [
        "JavaScript",
        "Python",
        "MongoDB"
    ]
}

O campo habilidades possui três valores.

Podemos consultar documentos que possuem uma determinada habilidade. 

db.alunos.find({

    habilidades: "MongoDB"

})

O MongoDB consegue encontrar documentos em que o array contém o valor informado.

📚 $all — Vários valores no mesmo array

O operador $all permite encontrar documentos cujo array contenha todos os valores especificados. 

db.alunos.find({

    habilidades: {
        $all: [
            "JavaScript",
            "MongoDB"
        ]
    }

})

O documento precisa possuir as duas habilidades.

📏 $size — Quantidade de elementos

O operador $size permite procurar arrays com uma quantidade específica de elementos. 

db.alunos.find({

    habilidades: {
        $size: 3
    }

})

Essa consulta encontra documentos cujo array habilidades possui exatamente três elementos.

🧩 Arrays contendo objetos

Arrays também podem armazenar documentos. 

{
    nome: "Ana",

    cursos: [

        {
            nome: "Banco de Dados",
            nota: 9
        },

        {
            nome: "Programação",
            nota: 8
        }

    ]
}

Agora temos um array chamado cursos que contém objetos.

🔗 Dot Notation

Para acessar campos dentro de documentos aninhados, podemos utilizar a chamada dot notation. 

db.alunos.find({

    "endereco.cidade": "Rio de Janeiro"

})

O ponto indica que queremos acessar um campo que está dentro de outro campo.

Pense assim:

endereco.cidade significa: campo cidade dentro de endereco.

🏠 Consultando documentos aninhados

Imagine os seguintes documentos: 

{
    nome: "João",

    endereco: {
        cidade: "São Paulo",
        estado: "SP",
        cep: "01000-000"
    }
}


{
    nome: "Maria",

    endereco: {
        cidade: "Rio de Janeiro",
        estado: "RJ",
        cep: "20000-000"
    }
}

Podemos encontrar pessoas do Rio de Janeiro: 

db.pessoas.find({

    "endereco.cidade": "Rio de Janeiro"

})

🔎 Consultando arrays de objetos

A dot notation também pode ser utilizada para consultar campos dentro de objetos armazenados em arrays. 

db.alunos.find({

    "cursos.nome": "Banco de Dados"

})

Essa consulta procura alunos que possuem algum curso com esse nome.

🔀 Operadores lógicos

Os operadores lógicos permitem combinar diferentes condições.

Operador Função
$and Todas as condições precisam ser atendidas.
$or Pelo menos uma condição precisa ser atendida.
$nor Nenhuma das condições deve ser atendida.
$not Nega uma condição.

🔗 $and

O operador $and permite definir explicitamente várias condições que precisam ser satisfeitas. 

db.produtos.find({

    $and: [

        {
            preco: {
                $gt: 100
            }
        },

        {
            estoque: {
                $gt: 10
            }
        }

    ]

})

O produto precisa ter preço maior que 100 e estoque maior que 10.

Observação:

Em muitos casos, o $and explícito não é necessário. Podemos simplesmente colocar as condições no mesmo objeto de filtro. 

db.produtos.find({

    preco: {
        $gt: 100
    },

    estoque: {
        $gt: 10
    }

})

🔀 $or

O $or é utilizado quando queremos aceitar uma condição ou outra. 

db.produtos.find({

    $or: [

        {
            categoria: "Eletrônicos"
        },

        {
            preco: {
                $lt: 100
            }
        }

    ]

})

O documento será retornado se pelo menos uma das condições for verdadeira.

🚫 $nor

O operador $nor encontra documentos que não atendem a nenhuma das condições informadas. 

db.produtos.find({

    $nor: [

        {
            categoria: "Eletrônicos"
        },

        {
            preco: {
                $lt: 100
            }
        }

    ]

})

Nesse caso, o documento não pode satisfazer nenhuma das duas condições.

❌ $not

O operador $not nega uma condição de comparação. 

db.produtos.find({

    preco: {
        $not: {
            $gt: 1000
        }
    }

})

A consulta procura valores que não sejam maiores que 1000.

🔍 $exists

O operador $exists permite verificar se um determinado campo existe no documento. 

db.produtos.find({

    desconto: {
        $exists: true
    }

})

Essa consulta procura produtos que possuem o campo desconto.

Também podemos procurar documentos onde o campo não existe: 

db.produtos.find({

    desconto: {
        $exists: false
    }

})

🧬 $type

O operador $type permite consultar documentos com base no tipo BSON de um campo.

Por exemplo, podemos procurar documentos em que determinado campo seja uma string. 

db.produtos.find({

    nome: {
        $type: "string"
    }

})

Isso pode ser útil quando estamos trabalhando com dados que possuem estruturas variadas.

🔤 $regex

O operador $regex permite procurar padrões dentro de strings.

Por exemplo: 

db.produtos.find({

    nome: {
        $regex: "note",
        $options: "i"
    }

})

A opção i indica que a busca não diferencia letras maiúsculas de minúsculas.

Atenção:

Regex pode ser bastante útil, mas consultas com padrões podem exigir cuidados de performance, principalmente em coleções grandes.

🧩 $elemMatch

Quando trabalhamos com arrays de documentos, o operador $elemMatch permite exigir que um mesmo elemento do array satisfaça várias condições.

Imagine: 

{
    nome: "Ana",

    cursos: [

        {
            nome: "Banco de Dados",
            nota: 9
        },

        {
            nome: "Programação",
            nota: 7
        }

    ]
}

Podemos procurar um curso chamado "Banco de Dados" com nota maior que 8: 

db.alunos.find({

    cursos: {
        $elemMatch: {
            nome: "Banco de Dados",
            nota: {
                $gt: 8
            }
        }
    }

})
Por que usar $elemMatch?

Ele deixa claro que as condições precisam ser satisfeitas pelo mesmo elemento do array.

🔥 Construindo uma consulta complexa

Agora podemos combinar vários conceitos.

Imagine uma coleção de alunos: 

{
    nome: "Carlos",

    idade: 22,

    endereco: {
        cidade: "Rio de Janeiro"
    },

    habilidades: [
        "JavaScript",
        "MongoDB"
    ],

    cursos: [

        {
            nome: "Banco de Dados",
            nota: 9
        }

    ]
}

Podemos procurar alunos que:

  • tenham idade maior ou igual a 18;
  • morem no Rio de Janeiro;
  • possuam MongoDB entre as habilidades. 
db.alunos.find({

    idade: {
        $gte: 18
    },

    "endereco.cidade": "Rio de Janeiro",

    habilidades: "MongoDB"

})

🔄 Pensando em SQL

Como você já estudou SQL, podemos comparar a ideia de uma consulta relacional com uma consulta MongoDB.

SQL 

SELECT nome, idade
FROM alunos
WHERE idade >= 18
AND cidade = 'Rio de Janeiro';

MongoDB 

db.alunos.find(

    {
        idade: {
            $gte: 18
        },

        "endereco.cidade":
            "Rio de Janeiro"
    },

    {
        nome: 1,
        idade: 1
    }

)
O objetivo da comparação:

perceber que os dois modelos conseguem realizar consultas, mas utilizam estruturas e mecanismos diferentes.

✅ Boas práticas

🎯 Seja específico

Utilize filtros que retornem apenas os dados realmente necessários.

👁️ Use projeção

Retorne somente os campos necessários para a operação.

📊 Pense em performance

Consultas complexas em grandes coleções podem exigir índices adequados.

🧠 Entenda o documento

Conhecer a estrutura dos documentos facilita a construção das consultas.

📝 Resumindo

O MongoDB permite armazenar arrays dentro dos documentos.

Documentos também podem possuir objetos aninhados.

A dot notation permite acessar campos dentro de estruturas aninhadas.

Operadores como $and, $or, $nor e $not permitem construir condições lógicas.

$exists verifica a existência de um campo.

$regex permite realizar buscas baseadas em padrões de texto.

$elemMatch é útil para consultar múltiplas condições dentro do mesmo elemento de um array de documentos.
