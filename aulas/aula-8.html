O que são funções de agregação?

Funções de agregação são funções SQL utilizadas para realizar cálculos sobre um conjunto de registros e produzir um resultado resumido.

Exemplo:

Em vez de retornar os 1.000 pedidos de uma loja, podemos calcular o valor total desses pedidos.

As principais funções que vamos estudar são:

COUNT

Contar

Conta registros ou valores.

SUM

Somar

Calcula a soma dos valores.

AVG

Média

Calcula a média.

MIN / MAX

Limites

Encontram o menor e o maior valor.

COUNT — contando registros

A função COUNT é utilizada para contar registros ou valores.

Imagine a tabela:

ID Nome Cidade
1 Ana Rio de Janeiro
2 João São Paulo
3 Maria Belo Horizonte

Podemos contar quantos clientes existem: 

SELECT
    COUNT(*) AS total_clientes

FROM clientes;

Resultado:

total_clientes
3
COUNT(*)

Conta as linhas retornadas pelo conjunto de dados.

COUNT(coluna)

Também podemos utilizar COUNT passando uma coluna. 

SELECT
    COUNT(email) AS total_emails

FROM clientes;

Nesse caso, o banco considera os valores não nulos daquela coluna.

COUNT(*) conta linhas.

COUNT(coluna) conta valores não nulos da coluna.

SUM — somando valores

A função SUM calcula a soma dos valores de uma coluna numérica.

Imagine a tabela de pedidos:

ID Total
101 350.00
102 120.00
103 500.00

Podemos descobrir quanto foi vendido: 

SELECT
    SUM(total) AS vendas_totais

FROM pedidos;

Resultado: 

vendas_totais
-------------
970.00

AVG — calculando médias

A função AVG calcula a média dos valores de uma coluna numérica. 

SELECT
    AVG(total) AS pedido_medio

FROM pedidos;

No nosso exemplo: 

(350 + 120 + 500) / 3

= 323.33

Portanto, o valor médio dos pedidos seria aproximadamente R$ 323,33.

MIN e MAX

Podemos descobrir o menor e o maior valor utilizando MIN e MAX. 

SELECT

    MIN(total) AS menor_pedido,

    MAX(total) AS maior_pedido

FROM pedidos;
menor_pedido maior_pedido
120.00 500.00

As principais funções

Função Objetivo Exemplo
COUNT Contar COUNT(*)
SUM Somar SUM(total)
AVG Calcular média AVG(total)
MIN Menor valor MIN(total)
MAX Maior valor MAX(total)

GROUP BY

Até agora calculamos informações considerando todos os registros.

Mas e se quisermos calcular algo por grupo?

Por exemplo:

Quantos clientes existem em cada cidade?

Podemos utilizar GROUP BY. 

SELECT
    cidade,
    COUNT(*) AS quantidade

FROM clientes

GROUP BY cidade;

O resultado poderia ser:

cidade quantidade
Rio de Janeiro 5
São Paulo 8
Belo Horizonte 3
Ideia principal:

O GROUP BY divide os registros em grupos de acordo com uma ou mais colunas.

GROUP BY com SUM

Também podemos calcular o total de vendas por cliente. 

SELECT

    cliente_id,

    SUM(total) AS total_gasto

FROM pedidos

GROUP BY cliente_id;

Agora cada cliente aparece uma vez e seu total é calculado separadamente.

cliente_id total_gasto
1 470.00
2 500.00

GROUP BY com JOIN

Agora podemos combinar o conhecimento da Aula 7 com o conteúdo desta aula.

Queremos descobrir quanto cada cliente gastou. 

SELECT

    c.nome,

    SUM(p.total) AS total_gasto

FROM clientes c

INNER JOIN pedidos p
    ON c.id = p.cliente_id

GROUP BY c.id, c.nome;

Resultado:

Cliente Total gasto
Ana 470.00
João 500.00
Observe:

O JOIN conecta as tabelas.

O GROUP BY cria os grupos.

O SUM calcula o total dentro de cada grupo.

GROUP BY com mais de uma coluna

Podemos agrupar utilizando mais de uma coluna.

Por exemplo, podemos calcular vendas por cidade e por cliente. 

SELECT

    cidade,

    cliente_id,

    SUM(total) AS total

FROM pedidos

GROUP BY
    cidade,
    cliente_id;

Nesse caso, os registros são agrupados pela combinação das duas colunas.

HAVING

O HAVING é utilizado para filtrar grupos depois que eles foram agrupados.

Imagine que queremos encontrar clientes que gastaram mais de R$ 500. 

SELECT

    cliente_id,

    SUM(total) AS total_gasto

FROM pedidos

GROUP BY cliente_id

HAVING SUM(total) > 500;
WHERE × HAVING

WHERE filtra registros antes do agrupamento.

HAVING filtra grupos depois do agrupamento.

WHERE × GROUP BY × HAVING

Podemos utilizar os três juntos.

Imagine que queremos:

  • Considerar apenas pedidos acima de R$ 100.
  • Agrupar por cliente.
  • Mostrar apenas clientes cujo total ultrapasse R$ 500. 
SELECT

    cliente_id,

    SUM(total) AS total_gasto

FROM pedidos

WHERE total > 100

GROUP BY cliente_id

HAVING SUM(total) > 500;

WHERE → filtra registros.

GROUP BY → agrupa registros.

HAVING → filtra os grupos.

ORDER BY com agregações

Podemos ordenar o resultado de uma agregação.

Por exemplo, queremos listar os clientes que mais gastaram primeiro. 

SELECT

    cliente_id,

    SUM(total) AS total_gasto

FROM pedidos

GROUP BY cliente_id

ORDER BY total_gasto DESC;

DESC coloca os maiores valores primeiro.

ASC coloca os menores valores primeiro.

Exemplo completo

Vamos juntar os conceitos.

Pergunta:

Quais clientes gastaram mais de R$ 500, considerando apenas pedidos acima de R$ 50?

Podemos escrever: 

SELECT

    c.nome,

    COUNT(p.id) AS quantidade_pedidos,

    SUM(p.total) AS total_gasto,

    AVG(p.total) AS media_pedidos

FROM clientes c

INNER JOIN pedidos p
    ON c.id = p.cliente_id

WHERE p.total > 50

GROUP BY c.id, c.nome

HAVING SUM(p.total) > 500

ORDER BY total_gasto DESC;

Essa consulta consegue mostrar, para cada cliente:

  • Quantidade de pedidos.
  • Total gasto.
  • Valor médio dos pedidos.

Como pensar em uma consulta desse tipo?

Uma boa maneira de entender consultas complexas é construí-las aos poucos.

  1. FROM → escolha a tabela principal.
  2. JOIN → conecte outras tabelas.
  3. WHERE → filtre registros.
  4. GROUP BY → crie os grupos.
  5. HAVING → filtre os grupos.
  6. SELECT → escolha as informações que serão exibidas.
  7. ORDER BY → organize o resultado.

Não é necessário memorizar tudo de uma vez.

O mais importante é entender o papel de cada cláusula.

COUNT DISTINCT

O DISTINCT permite considerar apenas valores diferentes.

Por exemplo, podemos descobrir quantas cidades diferentes existem: 

SELECT

    COUNT(DISTINCT cidade)
    AS cidades_diferentes

FROM clientes;

Se houver 100 clientes distribuídos em 10 cidades, o resultado será: 

cidades_diferentes
------------------
10

E os valores NULL?

As funções de agregação possuem comportamentos importantes quando existem valores NULL.

Por exemplo: 

SELECT
    AVG(total)

FROM pedidos;

Valores NULL não são considerados no cálculo da média.

Por isso, é importante conhecer a qualidade dos dados antes de interpretar uma agregação.

Resumo das cláusulas

Recurso Função

HAVING Filtra grupos.
ORDER BY Ordena o resultado.
COUNT Conta registros ou valores.
SUM Soma valores.

MIN Encontra o menor valor.
MAX Encontra o maior valor.

Resumindo

Funções de agregação permitem realizar cálculos sobre conjuntos de registros.

COUNT conta, SUM soma, AVG calcula médias, MIN encontra o menor valor e MAX encontra o maior.

GROUP BY permite dividir os registros em grupos.

HAVING permite filtrar esses grupos depois da agregação.

WHERE filtra registros antes do agrupamento.

JOIN + GROUP BY + funções de agregação permitem construir consultas muito mais poderosas.
