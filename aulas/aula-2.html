O que é um SGBD?

SGBD significa Sistema de Gerenciamento de Banco de Dados.

É um software responsável por fornecer mecanismos para criar, armazenar, consultar, modificar e administrar bancos de dados.

Em termos simples:

O SGBD funciona como uma camada intermediária entre as aplicações e os dados.

Onde o SGBD fica?

Podemos visualizar uma aplicação simples desta forma:

Interage com o sistema.

Aplicação

Processa as solicitações do usuário.

SGBD

Gerencia as operações sobre os dados.

Banco de Dados

Armazena as informações.

Imagine que o usuário deseja visualizar seus pedidos.

↓

↓

3. SGBD

↓

↓

5. SGBD

↓

Apresenta os dados ao usuário.

Como a aplicação conversa com o SGBD?

Para trabalhar com um banco de dados, a aplicação precisa estabelecer uma comunicação com o SGBD.

Essa comunicação normalmente envolve informações como:

🌐

Endereço

Onde o servidor do banco de dados está disponível.

🚪

Porta

Define o ponto de comunicação utilizado pelo serviço.

👤

Usuário

Identifica uma conta utilizada para acesso.

🔑

Autenticação

Permite verificar se o acesso é autorizado.

Importante:

Os detalhes de conexão dependem do SGBD, da configuração do ambiente e da aplicação.

O que podemos pedir ao SGBD?

Uma aplicação pode solicitar diferentes operações sobre os dados.

➕ Criar

Adicionar novos dados.

🔎 Consultar

Recuperar dados existentes.

✏️ Atualizar

Modificar dados existentes.

🗑️ Excluir

Remover dados.

Essas quatro operações são frequentemente resumidas pelo termo CRUD.

Onde entra o SQL?

Em um SGBD relacional, uma das formas mais conhecidas de expressar operações sobre os dados é utilizando SQL.

Por exemplo: 

SELECT *
FROM clientes;

Essa instrução solicita que sejam consultados os registros da tabela clientes.

Aplicação → envia uma operação.

SGBD → interpreta e executa a operação.

Banco de Dados → fornece os dados necessários.

O SGBD faz muito mais do que executar consultas

Um SGBD não serve apenas para receber comandos e devolver dados. Ele também possui diversas responsabilidades importantes.

Segurança

Controla quem pode acessar determinados recursos e realizar operações.

🔄

Transações

Ajuda a garantir que operações relacionadas sejam tratadas de forma consistente.

👥

Concorrência

Gerencia situações em que várias operações acontecem ao mesmo tempo.

💾

Persistência

Gerencia o armazenamento dos dados de acordo com o funcionamento do sistema.

E se várias pessoas acessarem ao mesmo tempo?

Imagine uma loja virtual com milhares de usuários. Várias pessoas podem consultar produtos e realizar pedidos simultaneamente.

O SGBD possui mecanismos para lidar com múltiplas operações acontecendo ao mesmo tempo e ajudar a preservar a consistência dos dados.

Exemplo:

Dois clientes tentam comprar o último produto disponível no estoque.

O controle de concorrência e as transações são importantes para evitar que operações simultâneas produzam resultados incorretos.

O que é uma transação?

Uma transação é uma unidade de trabalho formada por uma ou mais operações que devem ser tratadas de maneira consistente.

Um exemplo clássico é uma transferência bancária.

💰

Conta A

O valor precisa ser retirado da conta de origem.

➡️

Transferência

A operação precisa ser tratada como uma unidade lógica.

💵

Conta B

O valor precisa ser adicionado à conta de destino.

O conceito de transação será estudado com mais profundidade em aulas futuras.

Segurança e permissões

Nem todo usuário ou aplicação deve ter acesso irrestrito aos dados.

Um SGBD pode trabalhar com usuários, permissões e diferentes níveis de acesso.

Por exemplo, uma aplicação pode ter permissão para consultar e alterar determinados dados, enquanto outro usuário pode possuir permissões diferentes.

SGBD não é a mesma coisa que Banco de Dados

Essa é uma das diferenças mais importantes desta aula.

Banco de Dados SGBD
Contém os dados. É o software que gerencia os dados.
Pode conter tabelas, registros, índices e outros objetos. Fornece mecanismos para criar, consultar, alterar e administrar esses objetos.
Representa as informações armazenadas. Controla como essas informações são acessadas e manipuladas.

Atenção:

PostgreSQL, MySQL e MongoDB são nomes de produtos de software utilizados para gerenciamento de bancos de dados.

Eles não são a linguagem SQL.

Resumindo

SGBD é o software responsável por gerenciar bancos de dados.

A aplicação utiliza o SGBD para trabalhar com os dados.

O banco de dados contém os dados que serão armazenados e consultados.

Em bancos relacionais, o SQL é uma linguagem utilizada para expressar operações sobre os dados.

O SGBD também pode cuidar de aspectos como segurança, transações e concorrência.
