TRILHA DE BANCO DE DADOS

Curso de Banco de Dados

Aprenda os fundamentos de bancos de dados, SQL, NoSQL, MongoDB, Parquet e análise de grandes volumes de dados.

Trilha de estudos

Esta trilha foi organizada para levar você dos conceitos fundamentais até consultas, modelagem, NoSQL e análise de grandes volumes de dados.

Como estudar:

Siga as aulas na ordem. Cada aula apresenta um novo conceito e prepara você para os assuntos seguintes.
